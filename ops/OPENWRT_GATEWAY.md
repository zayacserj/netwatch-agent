# Главный OpenWrt-роутер для NetWatch

Эта инструкция восстанавливает сетевую часть, необходимую NetWatch.
Главный роутер выдаёт адреса по DHCP. Дополнительные точки доступа работают
мостом в этой же LAN. Для доступа снаружи провайдер должен доставлять
входящие TCP 80 и 443 на WAN роутера.

1. В LuCI настройте WAN по данным провайдера и проверьте интернет.
   Настройте LAN со статическим адресом и маской /24, включите DHCP на LAN
   и подключите Wi-Fi к LAN. Интерфейсы и зоны firewall называются
   `lan` и `wan`. Если меняется адрес LAN, сначала переподключитесь к
   роутеру по новому адресу.
2. Выберите IPv4-адрес Pi в этой LAN и определите MAC именно того сетевого
   интерфейса Pi, через который она подключена. Домен NetWatch должен
   указывать на публичный адрес WAN.
3. Скопируйте проверенный `openwrt-netwatch-gateway.sh` из репозитория
   на роутер. Подставьте домен, адрес Pi и её MAC:

   ```sh
   sh /tmp/openwrt-netwatch-gateway.sh DOMAIN PI_IPV4 PI_MAC
   ```

   Предварительная проверка показывает, какие записи уже есть и какие
   будут добавлены. Она проверяет конфликты резервирования и проброса.
4. После проверки примените тот же профиль:

   ```sh
   sh /tmp/openwrt-netwatch-gateway.sh --apply DOMAIN PI_IPV4 PI_MAC
   ```

   Скрипт резервирует IP Pi через DHCP, добавляет локальный DNS для
   домена NetWatch и пробрасывает WAN TCP 80/443 на Caddy. Настройки WAN,
   LAN и Wi-Fi задаются на первом шаге. Копии DHCP и firewall сохраняются
   в закрытом каталоге `/etc/netwatch-gateway-before.*`. При ошибке
   проверки или перезагрузки служб скрипт возвращает эти файлы.
5. Убедитесь, что Pi получила зарезервированный адрес, локальный DNS
   возвращает этот адрес, а HTTPS по домену открывается из домашней
   и внешней сети. Проверьте также вход на веб-монитор.
6. Получите свежий блок `/add_router` в Telegram и установите агент
   на OpenWrt. На роутере со старой рабочей привязкой установщик
   проверит её и сохранит идентификатор. На чистом OpenWrt блок выполнит
   первую привязку.

Этот профиль описывает настройки NetWatch. Полный перенос настроек
провайдера, Wi-Fi, VPN и Podkop выполняется по отдельной резервной копии
OpenWrt, совместимой с моделью роутера и версией прошивки.
