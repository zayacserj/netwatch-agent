# Windows Wizard для Raspberry Pi

[Скачать NetWatch-Pi-Wizard.exe](../../dist/NetWatch-Pi-Wizard.exe)

Wizard для Windows показывает шаги и готовит команды SSH/SCP. На чистой Raspberry Pi OS arm64 на базе Debian 13 нужны доступ по SSH, sudo и интернет для установки зависимостей.

- **С архивом Pi** выберите проверенный архив `.tar.gz`. Восстановятся сохранённые настройки и пользовательские базы.
- **Без архива** используется встроенный комплект с пустой SQLite. Скрипт установки запросит домен и данные для настройки Telegram и веб-монитора.

Сборка из рабочей ветки на Windows выполняется командой `python ops/windows-recovery/build.py`. Нужен компилятор `csc.exe` из .NET Framework. Результат появится в `dist/NetWatch-Pi-Wizard.exe`. Сборщик проверяет встроенный архив и берёт файлы из явно заданного списка. Полное восстановление на чистой SD-карте ещё предстоит проверить.

См. также [пошаговое восстановление](../../docs/Restore-clean-Pi.md).
